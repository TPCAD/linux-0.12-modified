# 8259A

8259A 是 i386 的可编程中断控制器（Programmable Interrupt Controller，PIC），用于对硬件产生的中断（外中断）与中断向量进行绑定。外中断分为**非可屏蔽中断**（Non-Maskable Interrupt）和**可屏蔽中断**。NMI 由 CPU 的 NMI 引脚接收，而可屏蔽中断则由 INTR 引脚接收。INTR 引脚连接的正是 8259A。

8259A 有 8 个中断信号线，一般将两片 8259A 串联以达到 15 个中断信号。

对 8259A 初始化需要按顺序向对应端口写入**初始化命令字**（Initialization Command Word）。

每片 8259A 都有一个命令端口和数据端口，主片分别为`0x20`和`0x21`，从片分别为`0xA0`和`0xA1`。

## ICW

初始化 8259A 必须按以下顺序向端口写入 ICW：

1. 向 0x21（主片）或 0xA1（从片）端口写入 ICW1
2. 向 0x20（主片）或 0xA0（从片）端口写入 ICW2
3. 向 0x20（主片）或 0xA0（从片）端口写入 ICW3
4. 向 0x20（主片）或 0xA0（从片）端口写入 ICW4

### ICW1

| 位 | 名称 | 描述 |
| --------------- | --------------- | --------------- |
| 0 | IC4 | 1 需要 ICW4，0 不需要 |
| 1 | SNGL | 1 单片 8259A，0 多片 |
| 2 | ADI | 对 8086/88 无用 |
| 3 | LTIM | 1 电平触发，0 边沿触发 |
| 4 | | 恒为 1 |
| 5 | A5 | 对 8086/88 无用 |
| 6 | A6 | 对 8086/88 无用 |
| 7 | A7 | 对 8086/88 无用 |

在 Linux 0.12 中，ICW1 被设置为`0x11`，表示中断请求时边沿触发、多片 8259A且需要 ICW4。

### ICW2

在 8086/88 处理器中 ICW2 用于设置中断号的高 5 位，与 8259A 自动设置的低 3 位（8259A 有 8 个中断信号线，编号从 0 到 7）组成一个 8 位的中断号。

在 Linux 0.12 中，主片的 ICW2 被设置为`0x20`，表示主片中断号范围是`0x20`～`0x27`。从片的 ICW2 被设置为`0x28`，表示从片中断号范围是`0x28`～`0x2f`。

### ICW3

ICW3 用于在多片级联时指明从片连接的主片引脚。

在 Linux 0.12 中，主片的 ICW3 被设置为`0x04`，表示主片的 IR2 引脚连接了从片。从片的 ICW3 被设置为`0x02`，表示从片连接在主片的 IR2 引脚上。

### ICW4

| 位 | 名称 | 描述 |
| --------------- | --------------- | --------------- |
| 0 | PM | 1 8086/88 系统，0 MCS80/85 系统 |
| 1 | AEOI | 1 自动结束中断方式，0 非自动结束中断方式 |
| 2 | M/S | 1 缓冲方式下主片，0 缓冲方式下从片 |
| 3 | BUF | 1 缓冲方式，0 非缓冲方式 |
| 4 | SFNM | 1 选择特殊全嵌套方式，0 普通全嵌套方式 |
| 5~7 |  | 恒为 0 |

在 Linux 0.12 中，主从片的 ICW4 都被设置为`0x01`，表示 8086/88 系统下普通全嵌套，非缓冲，非自动结束方式。

## OCW

完成初始化后可用向端口写入**操作命令字**（Operation Command Word）来监测 8259A 的工作状况或改变工作方式。

### OCW1

向`0x21`写入 OCW1 可以控制各中断信号的屏蔽状态。每一位对应芯片的一个中断信号，1 表示屏蔽对应中断，0 表示允许对应中断。

在 Linux 0.12 中，初始化 8259A 后，向主从片写入`0xff`屏蔽所有中断，在完成对应硬件的初始化后再允许对应中断。

### OCW2

向`0x20`写入 OCW2 可以向 8259A 发送 EOI 命令或设置中断优先级的自动循环方式。

| 位 | 名称 | 描述 |
| --------------- | --------------- | --------------- |
| 0~2 | L0~L2 | 3 位组成级别号，对应中断请求 IRQ0～IRQ7 |
| 3~4 | / | 恒为 0 |
| 5 | EOI | 非自动结束标志 |
| 6 | SL | 优先级设定标志 |
| 7 | R | 优先级循环状态 |

Linux 0.12 只使用 OCW2 发送 EOI 命令，值为`0x20`。

### OCW3

Linux 0.12 并没有使用该控制字。
