# I/O 端口

CPU 访问 I/O 设备需要知道设备的地址，也叫 I/O 端口。早期 x86 架构对设备地址有两种编址方式，**统一编址**和**独立编址**。

统一编址将设备端口归入内存地址空间，这种地址也叫**内存映射地址**。如 VGA 的显存地址`0xb8000`。CPU 访问一个端口的操作就像访问内存一样。独立编址则是把设备端口单独作为一个寻址空间，称为 I/O 地址空间，每个 I/O 地址对应一个端口。访问这种地址需要用到指定的指令（`in`、`out`）。

现代 x86 架构趋向于使用统一编址。

| 端口范围 | 描述 |
| -------------- | --------------- |
| 0x0000 - 0x001F | 第一个传统 DMA 控制器，常用于软盘 |
| 0x0020 - 0x0021 | 第一个 PIC |
| 0x0040 - 0x0047 | PIT |
| 0x0060 - 0x0064 | 8042 键盘控制器 |
| 0x0070 - 0x0071 | CMOS 和 RTC 寄存器 |
| 0x0080 - 0x008F | DMA 页面寄存器 |
| 0x0092          | 快速 A20 门寄存器 |
| 0x00A0 - 0x00A1 | 第二个 PIC |
| 0x00C0 - 0x00DF | 第二个 DMA 控制器 |
| 0x00E9          | |
| 0x0170 - 0x0177 | 副 ATA 硬盘控制器 |
| 0x01F0 - 0x01F7 | 主 ATA 硬盘控制器 |
| 0x0278 - 0x027A | 并行端口 |
| 0x02F8 - 0x02FF | 第二个串行端口 |
| 0x03B0 - 0x03DF | VGA 显示卡 |
| 0x03F0 - 0x03F7 | 软盘控制器 |
| 0x03F8 - 0x03FF | 第一个串行端口 |

## in/out 指令

```asm
in <general register>, <port address>
out <port address>, <general register>
```

`in`指令用于向端口写入数据，`out`指令用于读取端口数据。不能直接读写端口数据，必须通过寄存器操作。

因为访问 I/O 端口的速度并不如访问内存一样快，所以向 I/O 端口写入数据后应稍作等待再进行下一步操作。常见做法是在写入数据后加上两个跳转指令。

```asm
jmp .+2 # 当前地址加 2，也就是下一条指令
jmp .+2
```
