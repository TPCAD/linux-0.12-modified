# Bootloader

操作系统并不是计算机启动后运行的第一个程序。按下电源键后，计算机首先将「引导程序」（bootloader）加载到内存中。「引导程序」会对计算机硬件进行检测，并简单初始化硬件，然后寻找操作系统内核，将其加载到内存中，最后跳转到内核，并将控制权移交给内核。

编写 bootloader 不可避免地要和硬件打交道，一套统一的硬件接口可以为开发节约大量时间。在 32 位 CPU 上，硬件接口一般由 BIOS 提供，它允许开发人员使用汇编语言编写 bootloader，并通过中断指令访问硬件。而在 64 位 CPU 上，UEFI 取代了 BIOS 成为新一代的硬件接口。UEFI 仅仅提供了规范，并不提供实现，因此开发人员可以自由选择喜欢的编程语言实现 UEFI。
