# BIOS 中断

## int 0x10

`0x10` 中断是关于视频服务的中断，提供了包括设置显示模式，写字符和字符串，绘制图形像素等功能。

有关 VGA 的介绍可以在这里找到。

### ah=0x00 设置视频模式

```language
Function Code:
    AH = 0x00
Parameters:
    AL = 视频模式，见 https://mendelson.org/wpdos/videomodes.txt
         默认的视频模式一般是 0x03
Return:
    AL = 视频模式标记（不同 BIOS 可能会不相同）
         0x20 视频模式 > 7
         0x30 视频模式 0～5 和 7
         0x3f 视频模式 6
```

### ah=0x03 获取光标位置

参数：
  - AH = 0x03
  - BH = 页号

返回值：
  - AX = 0
  - CH = 起始扫描线
  - CL = 结束扫描线
  - DH = 光标所在行
  - DL = 光标所在列

### ah=0x0f 获取显示模式

参数：
  - AH = 0x0f
返回值：
  - AL = 显示模式（显示模式可参考[这个网站](https://mendelson.org/wpdos/videomodes.txt)）
  - AH = 字符列数
  - BH = 当前页号

### ah=0x12 bl=0x10 获取 EGA 信息

参数：
  - AH = 0x12
  - BL = 0x10
返回值：
  - BH = 视频状态，`0x00`表示彩色模式，`0x01`表示单色模式
  - BL = 显存大小
    - 0x00 = 64 KB
    - 0x01 = 128 KB
    - 0x02 = 192 KB
    - 0x03 = 256 KB
  - CH = 特性连接器信息
  - CL = 显卡开关设置

## int 0x13

`int 0x13` 是用于访问硬盘的 BIOS 中断。

BIOS 的硬盘驱动号从 0x80（0b1000_0000）开始。早期软盘的驱动号从 0x0（0b0000_0000）开始，后来硬盘出现后，将第七位置 1 以作区分。

### ah=0x00 重置硬盘

参数：
  - AH = 0x0
  - DL = 驱动器号，一般为 0x80

返回值：
  - CF = 错误则置位
  - AH = 错误码

### ah=0x02 读取硬盘到内存

参数：
  - AH = 0x02
  - AL = 扇区数，不能是 0
  - CH = 柱面号低 8 位
  - CL = 0～5 位为扇区号（扇区号从 1 开始计数），高 2 位为柱面号高 2 位
  - DH = 磁头号
  - DL = 驱动器号，一般为 0x80
  - ES:BX = 缓冲区地址

返回值：
  - CF = 错误则置位
  - AH = 错误码
    - 0x00：成功
    - 0x80：超时（常见于硬盘号错误）
  - AL = 实际读取的扇区数（只有部分 BIOS 支持）

```asm
# 从硬盘 0x80 的第二个扇区开始连续读取 4 个扇区到内存 0x90200
movw $0x9000, %ax                # 缓冲区基地址
movw %ax, %es
movw $0x0080, %dx                # 磁头号 0，驱动器号 0x80
movw $0x0002, %cx                # 磁道号 0，扇区号 2
movw $0x0204 ,%ax                # 功能号 2，扇区数 4
movw $0x200, %bx                 # 缓冲区偏移地址
int $0x13
```

### ah=0x15

参数：
  - AH = 0x15
  - DL = 驱动号
返回值：
  - CF = 错误则置位
  - AH = 磁盘类型
    - 0x00 = 无对应设备
    - 0x01 = 软盘
    - 0x02 = 软盘
    - 0x03 = 硬盘
  - CX:DX = 扇区数

### ah=0x88 获取扩展内存大小

返回值：
  - CF：错误则置位
  - AX：成功则为扩展内存大小，从 0x100000 开始，单位 KB；失败则为错误码
