# gcc

## 代码生成选项

### -fpic -fno-pic

Position Independent Code（PIC），是代码可以运行在内存的任意位置，而不需要重定位，常用于动态库。

但对于内核代码，因为内核总运行在固定位置，且构建时会链接所有符号，所以并不需要 PIC。

若开启 PIC，在编译内核时可能遇到「无法找到`__GLOBAL_OFFSET_TABLE__`」错误。

## x86 选项

### -m16 -m32 -m64

生成 16 位、32 位或 64 位环境的代码。

`-m32`将`int`，`long`和指针设置为 32 比特，生成运行在 32 位环境的代码。

`-m64`将`int`设置为 32 比特，`long`和指针设置为 64 比特，生成运行在 x86-64 架构的代码。

`-m16`与`-m32`相同，但汇编输出会在开始处加上`.code16gcc`使得其可在 16 位环境运行。

### -mmmx -msse -msse2 -msse3

用于开启 MMX，SSE 等扩展指令集。这些指令集都可以使用`-mno-`关闭。

编译器有时候会自动生成这些指令，早期的 CPU 并不支持这些指令，一旦执行就会引发崩溃。
