# 格式化字符串

## printf

```c
int printf(const char *fmt, ...);
```

参数`fmt`是一个包含零个或多个 format 标签的字符串，format 标签可以被随后可变参数的指定值替换并按要求格式化。format 标签的格式如下：

```language
%[flags][width][.precision][length]specifier
```

### 转换指示符（specifier）

**转换指示符**指明对应的标签应接受何种类型的参数，并以何种形式输出。

| specifier | description    |
|---------- | --------------- |
| a, A      | 以十六进制形式输出浮点数   |
| d         | 以十进制形式输出有符号整数（整数不输出符号）   |
| o         | 以八进制形式输出无符号整数（无前缀 0）   |
| x, X      | 以十六进制形式输出无符号整数   |
| u         | 以十进制形式输出无符号整数   |
| f         | 以小数形式输出单、双精度实数   |
| e, E      | 以指数形式输出单、双精度实数   |
| g, G      | 以 %f 或 %e 中较短的输出宽度输出输出单、双精度实数   |
| c         | 输出单个字符   |
| s         | 输出字符串   |
| p         | 输出指针地址 |
| lu        | 32 位无符号整数 |
| llu       | 64 位无符号整数 |
| n         | 保存目前为止已处理的字符数到指定地址 |
| %         | % |

### 标识（flags）

**标识**指明对齐方式，填充内容等。

| flags | description    |
|------ | --------------- |
| -     | 在给定宽度内左对齐，默认右对齐 |
| +     | 强制为数字加上符号 |
| 空格  | 在值前加入一个空格 |
| #     | 若值为非零整数，在前面加上对应的进制前缀；若值为小数则强制加上小数点 |
| 0     | 以 0 填充数字左边的空格 |

### 宽度（width）

**宽度**指明格式化结果的最小数目，使用数字直接指定，若使用`*`则表示在可变参数中指定（对应参数的前一个参数）。如果输出的值短于该数则用空格填充，如果长于该数则**不会**被截断。

### 精度（precions）

格式与宽度相同，但必须以`.`开头。宽度指定格式化结果的最小字符数，而精度指定要写入格式化结果的最小字符数。

对于整数（d、o、u、x、X），指明要写入的数字的最小位数。如果写入的值短于该数则用前导 0 填充，如果长于该数则**不会**被截断。

对于小数（e、E、f），指明小数点后的小数位数。

对于小数（g、G），指明要输出的最大有效位数。

对于字符串（s），指明要输出的最大字符数。

若为 0 表示不写入任何字符。未指定时默认为 1。

### 长度修饰符（length）

**长度修饰符**指明如何解释对应可变参数。

| length | description    |
|------- | --------------- |
| h      | 解释为短整型或无符号短整型，仅适用于整数 |
| l      | 解释为长整型或无符号长整型，仅适用于整数、字符（表示宽字符）或字符串（表示宽字符串） |
| L      | 解释为长双精度型，仅适用于浮点数 |

### 返回值

若成功，返回写入的字符总数，否则返回一个负数。

## vsprintf

```c
int vsprintf(char *buf, const char *fmt, va_list args);
```

`vsprintf`是 C 标准库中负责格式化字符字符串的函数。参数`buf`是格式化后的字符串，`fmt`是带有 format 标签的字符串，`args`则是可变参数地址。

`vsprintf`应逐字符扫描`fmt`字符串，将一般字符放入`buf`，当出现`%`时则开始解析 format 标签。

首先是**标识**。**标识**只可能是`-`、`+`、` `、`#`或`0`中的零个或多个，所以可以用一个整型的不同位来表示。

其次是**宽度**。**宽度**只能是数字或`*`，若是数字则解析随后字符得到**宽度**。若是`*`，则使用`va_arg`获取当前可变参数。若该参数是负数，则表示开启**标识**的`-`标记。

随后是**精度**。以`.`开头，其余与**宽度**相同，除了可变参数为负数时将取 0。

紧接着是**长度修饰符**，只能是`h`、`l`或`L`中的一个或没有。

最后是**转换指示符**。处理转换指示符的同时将格式化结果写入`buf`。

### number

```c
static char *number(char *str, int num, int base, int size, int precision,
                    int type);
```

`number`函数统一处理整型的参数，将数字转换为对应进制的字符串。
